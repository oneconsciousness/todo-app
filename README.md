# todo-app

A full-stack To Do list: a React and TypeScript web client and a Python REST API. A user signs in and creates, views, edits, reorders, searches and deletes their own tasks.

The project is being built in stages. The requirements and the decisions behind them are in [`docs/kickoff.md`](docs/kickoff.md); how we work is in [`CONTRIBUTING.md`](CONTRIBUTING.md).

Running instructions, the deployment guide and the project summary will be added as the apps land.
